# 九方小說編輯器 (Jiufang Novel Editor) v0.1.5-Beta

這是九方小說編輯器的 v0.1.5-Beta 測試預發布版。
在長篇小說創作過程中，除了正文撰寫，作品設定集（人物、世界觀、事件）的管理與跨作品復用，以及日常從外部資料來源整理筆記時的格式保持，皆是影響寫作節奏的重要環節。

本次更新重點聚焦於「編輯器底層規格統一」、「雙重貼上模式（格式保留 vs 純文字）」與「設定集卡片匯出與匯入功能」。同時落實了專案核心架構的瘦身與模組解耦，將 AI 提示詞外部化為獨立文字檔，並完成測試套件的分層重構，持續在維持系統極度穩定的前提下提升創作流暢度。

## 更新重點

### 1. 雙重貼上模式：靈活兼顧格式排版與乾淨純文字
- 支援標準貼上（Ctrl+V）：自網頁、筆記軟體或文書處理器貼上文字時，完整保留粗體、斜體等 Markdown 富文本結構，省去手動重新標註樣式的時間。
- 支援純文字貼上（Ctrl+Shift+V）：一鍵過濾外部來源的所有字體樣式與多餘排版，僅保留最純淨的文字內文，符合追求乾淨文字的創作者習慣。

### 2. 設定集資料庫匯出與匯入（跨作品設定復用）
- 資料集完整匯出：支援將右側資料集面板中的所有卡片（人物角色、世界觀、陣營、時間線）整體匯出為結構化 JSON 檔案。
- 智慧衝突防護匯入：支援匯入外部卡片資料集；若檢測到與現有專案同名之卡片，系統自動提示衝突處理選項，可彈性選擇「建立為新卡片（自動附加匯入標籤）」或「覆蓋現有卡片」，確保設定安全不覆蓋。

### 3. 編輯器底層規格統一與重構
- 建立統一的共用基底元件（BaseRichTextEdit），全面收斂主稿件編輯器與右側卡片編輯器。
- 統一雙側編輯器的 Markdown 語法高亮、字級縮放、排版快捷鍵與段落行距計算，消除過去兩側編輯手感不一致的細節差異。

### 4. 專案架構精簡與 AI 提示詞外部化
- 全面淘汰過時的舊版 JSON 存檔相容包袱，專案存檔路徑強制收斂至純 SQLite 資料庫架構，移除數百行歷史冗餘邏輯。
- 將角色提取、文學評語、世界觀整理、時間線梳理、續寫與靈感對話等 AI Prompt 模板從程式碼中剝離，外部化存放於 resources/prompts/ 目錄，便於創作者日後直接編輯調整模型指令。
- 抽取共用對話框元件 BaseDialog，統一封裝深淺色主題切換與全域高 DPI 縮放邏輯，精簡 22 個對話框的重複樣板程式碼。

### 5. 測試套件架構分層與 100% 綠燈驗證
- 將全專案測試檔依工程規範重新組織為 unit（單元測試）、integration（整合測試）與 ui（介面測試）三層結構。
- 全套 40 個測試模組、257 項自動化測試持續維持 100% 綠燈通過。
