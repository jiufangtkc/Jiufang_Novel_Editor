# 九方小說編輯器 (Jiufang Novel Editor) v0.1.7-Beta 發布說明

這是九方小說編輯器的 v0.1.7-Beta 測試發布版。

在長篇小說創作過程中，編輯器底層架構的穩定度與各類世界觀設定的流通備份至關重要。本次更新聚焦於專案核心架構的瘦身與重構，並新增「設定資料集匯出功能」，提供創作者將人物卡片與設定體系安全匯出與備份的管道。

---

## 本次更新重點

- 新增設定資料集匯出功能：支援將專案內的世界觀、人物與各類設定卡片獨立匯出為 Word（.docx）、Markdown（.md）或 JSON 備份檔，便於跨專案參考或封裝備份。
- 專案架構全面最佳化：完成核心代碼的模組化重構與型別標註強化，提升整體執行效能與介面響應速度，降低長時間寫作時的記憶體負載。
- 自動化測試套件維持 100% 綠燈：全套單元與整合測試全數通過驗證，確保功能擴充與重構未破壞既有穩定度。

---

## 檔案清單與說明

- `Jiufang_Novel_Editor_0.1.7-Beta-Setup.exe`：Windows 安裝版。下載後直接執行即可安裝並建立捷徑。
- `Jiufang_Novel_Editor_0.1.7-Beta.zip`：免安裝綠色版。下載解壓縮至任意資料夾，執行資料夾內的 `Jiufang_Novel_Editor.exe` 即可使用。

---

## 注意事項

- 本版本為 Beta 測試階段，進行大量文字寫作或匯出資料前，建議仍維持定期備份專案檔案（.db 格式）的良好習慣。
- 若在寫作過程中遇到任何問題或有實務流程建議，歡迎隨時至 GitHub Issues 提出交流討論。
